## デザインの方針（2026-11-02 作り直し・ハル「AI感がすごい。清潔感を。ホームページは集客導線」）

参考：royalsportsclub.jp（ハルのスクショ1枚＝最初の画面だけ見た。2ページ目以降は未確認）。
- 最初の画面は写真が主役：写真の上に細かい点の網、上の真ん中に白抜きのロゴ、左上に細い3本線のメニュー、字間を広くとったキャッチ＋手書き風の英字
- 白い地にたっぷりの余白、差し色はロゴの赤1色（`--accent`）、見出しは「手書き風の英字＋日本語」
- **集客の導線**：右下の丸い「体験予約」がずっと浮いている（予約フォームが見えている間だけ消える）。最初の画面（集合写真＋「世界一アットホームなボクシングジム」）→ About（5つの目的）→ コース（一般・キッズスクール）→ トレーナー紹介（実績で信頼）→ 「まずは、見学・体験から。」（流れ＋ボタン）→ 料金（→ まずは見学・体験から）→ 営業時間 → ジムのみんな（雰囲気）→ よくある質問（不安を消す）→ 予約フォーム → アクセス
- 写真は `images/` に置いて `<img class="photo" …>` で入れる（縦横の比率は CSS の aspect-ratio で切りそろえる）。最初の画面は `images/hero.jpg` を差し替えるだけで変わる

## 公開する前に（笹原さんに確かめる）

- **写真を載せてよいか**。とくに子どもの顔が写っている写真（hero・sandbags・kids-mitt・kids-class・kids-headgear・bbq・kid-gloves）
- **トレーナー紹介の写真**は選手時代の試合の写真で、新聞や大会のカメラマンが撮ったものかもしれない（撮った人の許可が要る可能性）。だめなら別の写真に差し替える
- 分からない4つ（体験の料金・持ち物・料金が税込かどうか・駐車場）は**ページに書いていない**（間違いを書かないため）。分かったら、体験の流れ・料金・よくある質問・アクセスに足す。いまは「よくある質問」で電話の問い合わせに案内している
- 言い回しを整えた所：About の締めの文、コースの説明、トレーナーの想い（短くまとめた）、よくある質問の答え（Wix の文から作った）
- 正式に公開するとき（笹原さんの了承・アドレスの用意ができたら）は `index.html` の検索よけ（noindex）の行を消す

## 体験予約のつなぎ方

1. GymKeep にオーナーでログイン → ☰「体験予約」→ 下の「受付の設定」で、体験の枠（曜日・時間・定員）・何日先まで・締め切り・
   お知らせ（持ち物など）・ジムの連絡先・このホームページのアドレスを入れて、「予約を受け付ける」にチェックして保存
2. 同じ画面の「予約ページ」の **「URLをコピー」** を押す（`https://boxinglog-gym-production.up.railway.app/t/<予約用の番号>` の形）
3. `index.html` の `<section class="sec" id="trial" data-booking-url="">` の `""` の中に貼る。ここ1か所だけ

- 予約用の番号は**招待番号（会員登録の入口）とは別**。公開してよい。いたずらが続いたら GymKeep の画面で作り直せる（そのときはここも貼り替える）
- URL が空・読み込めないとき・受付を止めているときは、フォームの代わりに案内（と GymKeep の予約ページへのボタン）が出る
- 予約した人へ自動のメールは送らない。確認の連絡はジムから電話などで（GymKeep の方針）
- 予約の記録は体験日から90日で消える。「来た」にすると GymKeep の名簿に「体験の人」として載る

## 手元で見る

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く。予約まで試すときは、手元で GymKeep を動かし、その予約ページの URL を `data-booking-url` に入れる。

## GitHub Pages で見られるようにする

1. リポジトリの Settings → Pages → Build and deployment の Source を「Deploy from a branch」、Branch を `main`・`/ (root)` にして Save
2. 数分で https://haru20190621-a11y.github.io/firststep-site/ で見られる。これを笹原さんに送って直しを聞く

### 笹原さんのアドレス（ドメイン）をつなぐ（形が決まってから）

1. 笹原さんがジムの名義でドメインを取る（パスワードはこちらに教えてもらわない）
2. リポジトリの Settings → Pages → Custom domain にそのドメインを入れて Save（リポジトリに `CNAME` ができる）
3. 笹原さんのドメインの管理画面で、GitHub の案内どおりの DNS の設定を入れてもらう（画面を一緒に見ながら案内する）
4. つながったら Pages の「Enforce HTTPS」にチェック
5. GymKeep の「受付の設定」の「ジムのホームページ」を新しいアドレスに変える
