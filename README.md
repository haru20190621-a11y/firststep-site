## デザインの方針（2026-11-02 作り直し・ハル「AI感がすごい。清潔感を。ホームページは集客導線」）

参考：royalsportsclub.jp（ハルのスクショ1枚＝最初の画面だけ見た。2ページ目以降は未確認）。
- 最初の画面は写真が主役：写真の上に細かい点の網、真ん中に白いロゴ、左上に細い3本線のメニュー、字間を広くとったキャッチ＋手書き風の英字
- 白い地にたっぷりの余白、差し色は青1色（`--accent`）、見出しは「手書き風の英字＋日本語」
- **集客の導線**：右下の丸い「体験予約」がずっと浮いている（予約フォームが見えている間だけ消える）。最初の画面 → 目的 → 「まずは、体験から。」（流れ・料金・持ち物＋ボタン）→ 料金（→ まずは体験から）→ 営業時間 → よくある質問（不安を消す）→ 予約フォーム → アクセス
- 写真が届くまでは灰色の枠（`.ph`）。写真は `images/` に置き、`<div class="ph …">` を `<img class="photo" src="images/…" alt="…">` に差し替える。最初の画面は `images/hero.jpg` を置くだけで出る

## 体験予約のつなぎ方

1. GymKeep にオーナーでログイン → ☰「体験予約」→ 下の「受付の設定」で、体験の枠（曜日・時間・定員）・何日先まで・締め切り・
   お知らせ（持ち物など）・ジムの連絡先・このホームページのアドレスを入れて、「予約を受け付ける」にチェックして保存
2. 同じ画面の「予約ページ」の **「URLをコピー」** を押す（`https://boxinglog-gym-production.up.railway.app/t/<予約用の番号>` の形）
3. `index.html` の `<section class="sec" id="trial" data-booking-url="">` の `""` の中に貼る。ここ1か所だけ

- 予約用の番号は**招待番号（会員登録の入口）とは別**。公開してよい。いたずらが続いたら GymKeep の画面で作り直せる（そのときはここも貼り替える）
- URL が空・読み込めないとき・受付を止めているときは、フォームの代わりに案内（と GymKeep の予約ページへのボタン）が出る
- 予約した人へ自動のメールは送らない。確認の連絡はジムから電話などで（GymKeep の方針）
- 予約の記録は体験日から90日で消える。「来た」にすると GymKeep の名簿に「体験の人」として載る

## 手元で見る

```bash

```

ブラウザで http://localhost:8000 を開く。予約まで試すときは、手元で GymKeep を動かし、その予約ページの URL を `data-booking-url` に入れる。

1. リポジトリの Settings → Pages → Build and deployment の Source を「Deploy from a branch」、Branch を `main`・`/ (root)` にして Save
